# RTK 点位图纸对齐教程

## 1. 启动

- 在仓库根目录双击 `启动RTK图纸预览.bat`，打开布置图 1112 页面。
- 手动启动时，在仓库根目录执行 `python -m http.server 8766 --bind 127.0.0.1`，浏览器访问 `http://localhost:8766/tools/rtk_preview/rtk_points_1112.html`。
- 页面需要联网加载 Leaflet 1.9.4；`file://` 直接打开可能一直显示“加载中”。

## 2. 文件位置

| 内容 | 位置 |
|------|------|
| 点位序列 | `src/rtk_nav/rtk_nav/config/rtk_points.md` |
| 矢量底图 | 仓库根目录 `布置图1112.svg` |
| 对齐页面 | `tools/rtk_preview/rtk_points_1112.html`（内嵌底图和生成时的点位） |

`rtk_points.md` 由机器人 `WAIT_RTK` 自动追加，不要手改；混合场地按 `seq` 拆成独立文件。

## 3. 重新生成布置图 1112 页面

`WAIT_RTK` 追加采点后，在仓库根目录运行下面的命令，再刷新浏览器。页面按 WGS84 读取现场采点，初次打开会近似摆放点位。

```powershell
python tools/plot_rtk_points.py --input src/rtk_nav/rtk_nav/config/rtk_points.md --output tools/rtk_preview/rtk_points_1112.html --background-image "布置图1112.svg"
```

页面左侧“源坐标系”可切换 WGS84 / GCJ02 / BD09：选中的坐标系会先转换为 WGS84，再计算 UTM、标定和显示。BD09/GCJ02 数据选错会导致点位整体偏移数百米到 1 km。

- `--input`：默认点位序列。
- `--coord-system`：点位文件坐标系（`wgs84`/`gcj02`/`bd09`），页面会转换为 WGS84。
- `--dataset "名称=路径"`：可将 `config` 中的其他点位记录加入页面“点位序列”下拉框。
- 换底图或改分辨率后，控制点 `px/py` 会变化，必须重新标定。
- `--reference-point NAME,LON,LAT`：在带底图页面叠加青色参考点，支持重复指定。

## 4. 对准步骤

1. **初判方向**：用“水平镜像 / 垂直镜像 / 旋转180° / 旋转 / 平移 / 缩放”调整底图；点位始终不动。确定大致方向后点击“重置”，再开始精确拾取。调整后的底图只是显示状态，直接在调整状态下拾取会把显示变换混入控制点像素坐标。
2. **精确标定**：左侧选择一条采点 → “在图纸上拾取” → 点击图上对应位置。至少选 3 个不共线、相距较远且特征清晰的控制点，优先覆盖图纸的不同区域。三点及以上使用仿射变换，允许图纸存在横纵比例差或轻微倾斜。
3. **两点状态**：只有 2 个控制点时页面只显示“临时两点定位”。两点可以得到零残差，但不能验证方向，不能据此判断标定可信。
4. **交叉验证**：三点仿射模型会精确穿过这三个控制点，因此应再选择第 4 个未参与拟合的点。点击时页面会先显示旧模型预测误差，误差应小于 2 px；误差较大时删除并重拾最近加入的控制点。
5. **判断 RMSE**：4 个及以上控制点参与拟合时，RMSE 应小于 20 px，控制点残差也应保持较小。超过阈值时页面回退近似摆放，绿色点位不是可信标定结果。
6. **导出**：需要保存本次标定时，点“导出标定 JSON”，自行选择保存位置。JSON 会保存控制点、模型类型和底图显示设置。
7. **恢复**：用自己的标定文件重新生成时，加 `--calibration 标定.json`。页面会读取控制点并恢复底图的缩放、旋转、镜像和平移。若 `control_points` 为空，页面会恢复底图设置，点位仍按近似位置显示。

辅助功能：点“拾取坐标（估算经纬度）”，再点图纸任意位置，左下角显示该点的 `lat,lon` 与 UTM，可复制。已完成标定时用标定反算；未标定时用近似摆放估算（结果仅供参考）。

页面默认逐个绘制所有点位，即使多个点位落在同一位置也不会合并。点位标签重叠时默认仍全部显示；如果图纸过密，可勾选“标签自动避让”隐藏重叠标签。

## 5. 常见问题

- **标定不可信**：4 个及以上控制点的 RMSE 超过 20 px 时页面会提示“控制点与图上位置不匹配”，并自动回退近似摆放，不会再用错误参数移动整页点位。删掉偏差大的控制点，换更远、位置明确的点重试。
- **两点方向反了**：这是临时两点定位的已知限制。两点间东西向差异很小时，方向由很小的横向点击误差决定。继续添加不共线控制点，完成仿射标定并用第 4 个点验证。
- **三点 RMSE 很大**：三点实际位置可以都正确，但它们的 UTM 三角形与图纸像素三角形不满足等比例相似变换。新版使用仿射变换处理横纵比例差和轻微倾斜。若仍然异常，检查点位编号是否对应。
- **点位整体歪 90°、RMSE 很大**：底图镜像方向不对，先试垂直/水平镜像，再重新拾取。
- **点位跑到图外**：选错点位序列，或该场地尚未标定（虚线为近似摆放）。
- **缩放时底图翻转**：旧页面问题，重新生成即可；镜像已放在 Leaflet 不会改写的容器上。
- **页面卡在“加载中”**：确认通过 `http://localhost:8766` 访问且能联网加载 Leaflet。
